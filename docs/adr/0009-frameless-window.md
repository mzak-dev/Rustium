# Frameless window with our own title-bar controls

The main window has no system decorations; minimize, maximize and close live in the HUD as in the mockups. Dragging uses winit's `drag_window` (the system move loop keeps Aero Snap), resizing uses `drag_resize_window` from a thin border band, and on Windows `with_undecorated_shadow(true)` keeps the drop shadow. Windows 11 Snap Layouts need the maximize button to answer `WM_NCHITTEST` with `HTMAXBUTTON`, which winit cannot do, so the `rustium-platform` crate subclasses the window procedure (`SetWindowSubclass`) and also answers `HTCAPTION` for the empty part of the top strip and the resize edges. The app reports the rectangles every frame; the answer logic is plain Rust and unit-tested, only the thin Win32 layer is `unsafe` and runs inside `catch_unwind`. Off Windows the crate does nothing and the winit calls above remain the only mechanism.
